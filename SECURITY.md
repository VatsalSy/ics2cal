# Security Policy

## Supported Versions

- Latest released version
- Main branch (best effort)

## Reporting a Vulnerability

- Prefer a private report: contact [VatsalSy](https://github.com/VatsalSy).
- If private contact is not possible, open a minimal public issue without exploit details; a maintainer will respond and provide a private channel.
- Include in your report:
  - Affected version or commit
  - Reproduction steps
  - Impact assessment

We aim to acknowledge reports within 7 days and, when confirmed, coordinate on a fix and disclosure timeline.
