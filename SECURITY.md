# Security Policy

## Supported Versions
- Latest released version
- Main branch (best effort)

## Reporting a Vulnerability
- Prefer a private report: contact [VatsalSy](https://github.com/VatsalSy).
- If neither is possible, open a minimal public issue without exploit details; a maintainer will provide a private channel.
- Please include:
  - Affected version/commit
  - Reproduction steps
  - Impact assessment

We aim to acknowledge reports within 7 days and, when confirmed, coordinate on a fix and disclosure timeline.
